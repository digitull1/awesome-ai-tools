## Conventions

| Mark | Meaning |
|---|---|
| **HOST:** | Scripted words, spoken to camera. Say them in your own voice, but keep the structure and every claim. |
| **VO:** | Voiceover, recorded after the edit so it can match the real footage. |
| **PRACTITIONER / SUBJECT (capture):** | Unscripted. The script gives the questions to ask and what the edit needs. Never feed people answers. |
| **PICTURE:** | What we see: A-roll, B-roll, screen recordings. |
| **ON SCREEN:** | Text and graphics, in the brand style from [02-packaging.md](../02-packaging.md#41-brand-tokens-taken-from-offladdercom). |
| **> Retention:** | Why this beat is here, and the device it uses. Delete these notes from the teleprompter copy. |
| **[HOST: real]** | Replace with the host's true experience. Never perform an invented anecdote. |
| **[FACT-CHECK: …]** | A claim that needs a primary source in the claims register ([templates/claims-register.md](../templates/claims-register.md)) before recording. |
| **[CAPTURE: …]** | A moment the shoot must get, because the edit depends on it. |
| **{curly braces}** | A value that only exists after research or filming (counts, times, results). |

**Timings** assume roughly 150 spoken words a minute. After the table read, cut about 20%: a script always runs longer on camera than on paper.

**Outcome branches.** Experiments can't be scripted to a result. Where the outcome decides the packaging, the script gives both branches, and the title is locked only after the edit ([02-packaging.md](../02-packaging.md#31-rules), rule 8).
